## 🧠 About Me

I'm a **Python developer and ML engineer** specializing in computer vision, IoT health analytics, and intelligent systems. I love building pipelines that extract meaning from real-world sensor data — whether that's spatial coordinates, posture patterns, or bio-signals.

📺 I create content on **YouTube**, share deep-dives on **Medium**, and connect with the community on **Instagram**.

- 🔭 Currently working on: AI-powered health & posture detection systems
- 🌱 Learning: Deep learning architectures, edge AI & TinyML
- 🧪 Fun fact: I've processed **50,000+ spatial coordinate records** in a single pipeline
- ⚡ Belief: Clean code + smart models = real-world impact
- 🎯 Goal: Building technology that genuinely improves people's lives
